# Twilight badge art — first review

Five concepts for art direction review, generated with the built-in image generation tool. These are samples, not approved final artwork. The other 28 badges remain labeled placeholders in the app.

| Sample | Badge class | What it tests |
|---|---|---|
| `first-sight` | Scene — The Cullens Arrive | Character likeness, rain, tension, group storytelling |
| `twilight` | Final movie — Twilight | Romantic payoff, warm lights against a cold forest |
| `breakfast` | Meal — Brunch | Food, texture, warm interiors, continuity without characters |
| `secret-scenes` | All scenes — Twihard | A symbolic reward that reads as a collection achievement |
| `secret-immortal` | Ultimate completion — Immortal | A more elaborate reward, ruby apple, silver foliage, forever |

Open `contact-sheet.jpg` for the overview. `originals/` contains the full-resolution PNGs returned by the generator; `web/` contains 768px WebPs already wired into the app. The complete exact prompts are in `prompts.json`. Original files have not been cropped or painted over.

The proposed direction is gothic romance cover art with fantasy game reward detail: blue-green forests, silver rain, burgundy accents, warm light, and painterly surfaces. Labels are handled by the app rather than painted into the art.

Useful feedback: more obvious brushwork versus the current polished realism; closeness to the film actors; how much decorative symbolism feels right; contrast/readability at small badge size; whether the ultimate reward should feature characters or only the emblem. The app uses circle, arch, and rounded-square crops, so central subjects matter.

Files named `breakfast` retain the existing internal ID; the visible badge is **Brunch** at 11 a.m.
